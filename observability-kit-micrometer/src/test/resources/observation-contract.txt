# The public span surface of Observability Kit: every Observation the kit can
# emit, its span name, and its low- and high-cardinality attribute keys.
# Span names and attributes are consumed by dashboards and trace queries
# outside this repository, so treat any change to this file as a breaking
# change and call it out in the release notes.
#
# Values embedding fixture data (e.g. the navigation span name) come from the
# scenarios in ObservationContractTest, which drives every emitter with all
# optional attributes present. To update: run the test and copy the actual
# inventory it prints.
